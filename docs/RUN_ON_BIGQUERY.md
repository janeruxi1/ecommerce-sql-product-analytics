# Running the cases on BigQuery

Everything runs in the free **BigQuery sandbox**: no billing account and no card. The sandbox
allows 1 TiB of query processing a month; one full run of this repository scans well under that
(the dry run prints the exact figure first). The commands below run in **Google Cloud Shell**, a
terminal in the browser that is already signed in, so no keys are created or downloaded.

## 1. Create a project (once, about 5 minutes)

1. Open the [BigQuery console](https://console.cloud.google.com/bigquery) and sign in with a
   Google account.
2. When asked, create a project (any name, for example `sql-casebook`). Without billing it runs
   in sandbox mode, shown by a "Sandbox" label at the top of the page.
3. Note the **project id** shown in the project picker (it may have a number added, for example
   `sql-casebook-481210`).

## 2. Run the cases (about 5 minutes)

Open **Cloud Shell** (the `>_` icon at the top right of the console) and run:

```bash
git clone https://github.com/janeruxi1/ecommerce-sql-product-analytics.git
cd ecommerce-sql-product-analytics
python3 -m venv ~/casebook-venv && source ~/casebook-venv/bin/activate
pip install -r requirements.txt google-cloud-bigquery

python scripts/run_bigquery.py --project YOUR_PROJECT_ID --dry-run   # bytes each query would scan
python scripts/run_bigquery.py --project YOUR_PROJECT_ID             # run all, save results/
```

The runner dry-runs every query first and stops before running anything if a query would scan
more than 50 GB. Results are written to `results/<case>/<query>.csv`, and
`results/run_record.json` records when each query ran and what it scanned.

If Cloud Shell asks to authorize the call, accept: it lets the shell use your own account.

## 3. Bring the results back

In Cloud Shell, zip the results and download the zip (⋮ menu → *Download*, path
`ecommerce-sql-product-analytics/results.zip`):

```bash
zip -r results.zip results
```

Unzip it into the repository on your computer, then commit the `results/` folder.

## Notes

* **theLook changes.** theLook eCommerce is synthetic and regenerated by Google, so counts differ
  between runs. `results/run_record.json` holds the run date; the analysis windows (2023–2025)
  are fixed in each query's `params` block.
* **Running one case:** `--only 03` runs the cases whose folder starts with `03`.
* **Running a query by hand:** `python scripts/print_query.py 03_cohort_retention/cohort_matrix`
  prints the query with the real table names, ready to paste into the BigQuery console
  (`--list` shows all queries).
